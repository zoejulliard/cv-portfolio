# Data Science Portfolio — Zoé Julliard--Bonnouvriée

Bienvenue sur le dépôt de mon portfolio interactif en **Data Science & Intelligence Artificielle**. 

Ce site web dynamique met en valeur mes compétences techniques, mes projets académiques et mes expériences professionnelles.

**Découvrir le portfolio en ligne :** [https://zoejulliard.github.io/cv-portfolio/](https://zoejulliard.github.io/cv-portfolio/)

---

## Points Forts du Portfolio

- **Bilingue (FR / EN) :** Bascule instantanée de l'intégralité du contenu et téléchargement automatique de la version adéquate du CV (PDF).
- **Projets Détaillés :** Case studies approfondis (objectifs, métriques clés, architectures et interprétations économétriques/techniques).
- **Expérience Interactive :** Présentation du stage en IA Agentique chez AVISIA avec intégration directe de la lettre de recommandation.
- **Visualisations :** Radar de compétences interactif propulsé par Chart.js.

---

## 🛠️ Stack Technique

- **Frontend :** HTML5, CSS3 (CSS Variables, Flexbox, Grid), JavaScript (ES6+Vanilla)
- **Librairies JS :** [Chart.js](https://www.chartjs.org/) (Radar chart des compétences)
- **Déploiement :** GitHub Pages
